# Додаток 4. Програмне забезпечення

Курс побудовано на прикладі Autodesk Fusion для параметричного 3D-моделювання, Inkscape для створення векторної графіки та SVG, PrusaSlicer для підготовки моделей до 3D-друку, Python API Autodesk Fusion для автоматизації й доступного в закладі засобу штучного інтелекту як допоміжного інструмента. Цей комплект є прикладом реалізації програми, а не обов’язковою вимогою.

| **Завдання курсу** | **Приклад програмного забезпечення** | **Придатні аналоги** | **Умови відтворення завдань** |
| --- | --- | --- | --- |
| Параметричне 3D-моделювання деталей і тіл обертання, робота з ескізами, розмірами, операціями та складаннями | Autodesk Fusion | FreeCAD; Onshape; Solid Edge; SOLIDWORKS Education | Аналог має підтримувати параметричні ескізи, твердотільні операції, імпорт SVG, складання та експорт STL або 3MF. Назви команд і послідовність дій учитель адаптує до обраної програми. |
| Створення особистого логотипа й підготовка векторного контуру | Inkscape | CorelDRAW; Adobe Illustrator; Affinity Designer | Потрібні робота з кривими, перетворення тексту й об’єктів у контури та коректний експорт SVG. Перед імпортом у CAD перевіряють масштаб і замкненість контурів. |
| Підготовка моделі до 3D-друку | PrusaSlicer | UltiMaker Cura; OrcaSlicer; Bambu Studio | Обирають сумісний профіль обладнання й матеріалу; відтворюють орієнтацію моделі, висоту шару, заповнення, підтримки, перевірку шарів та експорт керувального файла. Конкретні значення визначають відповідно до обладнання закладу. |
| Автоматизація повторюваних операцій і створення параметричних моделей | Python API Autodesk Fusion | Python API FreeCAD; FeatureScript в Onshape; макроси або API інших CAD-систем | Код між середовищами безпосередньо не переноситься. Зберігають навчальну мету: параметри, послідовність побудови, перевірку результату, опрацювання помилок і пояснення коду. |
| Допомога з поясненням коду, пошуком помилок та порівнянням варіантів | Доступний у закладі засіб штучного інтелекту | ChatGPT; Microsoft Copilot; Google Gemini; Claude або інший дозволений сервіс | Використання узгоджують із правилами закладу, віковими обмеженнями сервісу та вимогами захисту персональних даних. Учень перевіряє код і твердження за офіційною документацією та відповідає за кінцевий результат. |
| Підготовка звіту у форматі DOCX або PDF | Microsoft Word | LibreOffice Writer; Google Документи; ONLYOFFICE | Засіб має підтримувати послідовне розміщення пронумерованих скріншотів, підписів до них і експорт у PDF. |

Заміна програмного забезпечення не повинна змінювати очікувані результати навчання, кількість годин і критерії оцінювання. Один аналог може відтворювати лише частину функцій базового комплекту, тому перед початком роботи вчитель перевіряє підтримку потрібних операцій, форматів файлів і доступність облікових записів. Ліцензійні умови, системні вимоги та функціональні обмеження уточнюють на офіційних сайтах розробників на момент упровадження курсу.

Офіційні сторінки для перевірки актуальних можливостей: Autodesk Fusion for Education — https://www.autodesk.com/education/edu-software/fusion; FreeCAD — https://www.freecad.org/; Onshape for Education — https://www.onshape.com/en/education/plans; Inkscape — https://inkscape.org/; PrusaSlicer — https://www.prusa3d.com/page/prusaslicer_424/; UltiMaker Cura — https://ultimaker.com/software/ultimaker-cura/.
