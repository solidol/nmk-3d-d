# Урок 26. Проєктування простого механізму

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Розробити посильну концепцію механізму.

## Підготовка

Візьміть за основу один тип руху, розглянутий на уроці 27.

## Зміст

- призначення простої іграшки-антистресу
- схема руху одного вузла
- перелік деталей та їхні функції
- вимоги до розмірів і взаємного розташування

## Хід уроку та завдання

- розробити посильну концепцію механізму
- створити ескіз деталей і схему руху
- описати функції та погодити конструкцію без обов’язкової зубчастої передачі
