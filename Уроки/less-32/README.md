# Урок 32. Фінальний проєкт: перевірка й слайсинг

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Перевірити модель і виконати слайсинг за профілем принтера.

## Підготовка

Модель уроку 31 і перевірений профіль принтера.

## Зміст

- перевірка геометрії та відповідності вимогам
- орієнтація моделі й параметри слайсингу
- оцінка тривалості друку для спільного графіка
- підготовка слайдів про результат і технічне рішення

## Хід уроку та завдання

- перевірити модель і виконати слайсинг за профілем принтера
- пояснити вибір основних налаштувань
- підготувати два слайди та дані для графіка друку



[Завершальний етап роботи № 10](../less-35/README.md#практична-робота--10).

## Перевірка результату

Покажіть шари слайсингу, обґрунтуйте підтримки й запишіть час для графіка друку.
