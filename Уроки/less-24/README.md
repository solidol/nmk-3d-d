# Урок 24. Тіла й компоненти. Структура збірки

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Створити просту модель із двома компонентами.

## Підготовка

Дві прості деталі, наприклад основа й накладка.

## Зміст

- відмінність тіла від компонента
- організація елементів у браузері моделі
- створення окремих компонентів
- взаємне розташування деталей збірки

## Хід уроку та завдання

- створити просту модель із двома компонентами
- надати компонентам зрозумілі назви
- показати структуру моделі та пояснити призначення її елементів

## Перевірка результату

Виберіть кожен компонент у браузері й покажіть його тіло та місце у збірці.
