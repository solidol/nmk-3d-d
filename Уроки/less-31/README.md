# Урок 31. Фінальний проєкт: моделювання

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Створити модель відповідно до вимог проєкту.

## Підготовка

Погоджені ескіз і вимоги уроку 30.

## Зміст

- послідовність моделювання за погодженим задумом
- застосування вивчених операцій і, за потреби, автоматизації повторюваних побудов
- перевірка проміжних розмірів і форми
- фіксація основних етапів для звіту

## Хід уроку та завдання

- створити модель відповідно до вимог проєкту
- перевірити основні розміри й усунути виявлені помилки
- зібрати пронумеровані скріншоти з підписами



[Завершальний етап роботи № 10](../less-35/README.md#практична-робота--10).

## Перевірка результату

Звірте габарити й функціональні елементи з вимогами. Скріншотами зафіксуйте ключові зміни.
