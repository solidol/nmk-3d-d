# Урок 18. Створення параметричної геометрії скриптом

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Доповнити наданий скрипт створенням простої параметричної форми.

## Підготовка

Робоча копія скрипту уроку 17 та два набори допустимих розмірів.

## Зміст

- створення документа, ескізу та базових геометричних елементів
- передавання розмірів через параметри скрипту
- виконання операції побудови та перевірка результату
- повторний запуск із новими значеннями без ручної перебудови

## Хід уроку та завдання

- доповнити наданий скрипт створенням простої параметричної форми
- перевірити щонайменше два набори коректних параметрів
- зафіксувати код і відповідні результати виконання



[Завершальний етап роботи № 9](../less-21/README.md#практична-робота--9).

## Перевірка результату

Звірте введені та виміряні габарити для двох запусків. Збережіть знімки для роботи № 9.
