# Урок 20. Перевірка й налагодження скриптів

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Знайти помилки в наданому фрагменті скрипту.

## Підготовка

Навчальний скрипт із підготовленою вчителем помилкою та описом очікуваного результату.

## Зміст

- повідомлення про помилки та пошук проблемного кроку
- поетапний запуск і перевірка проміжного результату
- звіряння команд із довідкою програмного інтерфейсу
- критична перевірка коду, запропонованого ШІ

## Хід уроку та завдання

- знайти помилки в наданому фрагменті скрипту
- виправляти код поетапно та перевіряти результат після кожної зміни
- пояснити причину помилки й спосіб її усунення
