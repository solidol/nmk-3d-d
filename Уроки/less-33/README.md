# Урок 33. Фінальний проєкт: друк, аналіз і матеріали презентації

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Проаналізувати результат друку свого проєкту за графіком.

## Підготовка

Цифрова модель, виріб за графіком виготовлення й чернетка звіту.

## Зміст

- виготовлення за погодженим графіком
- порівняння виробу з моделлю та вимогами
- аналіз відхилень і можливих удосконалень
- завершення звіту та матеріалів спільного показу

## Хід уроку та завдання

- проаналізувати результат друку свого проєкту за графіком
- завершити звіт із фінальним скріншотом і змістовними підписами до всіх скріншотів
- передати два слайди й відео або озвучені слайди до уроку 34



[Завершальний етап роботи № 10](../less-35/README.md#практична-робота--10).

## Перевірка результату

Порівняйте щонайменше одну характеристику виробу з моделлю. Звіт, два слайди й відео або озвучені слайди мають бути готовими до уроку 34.
