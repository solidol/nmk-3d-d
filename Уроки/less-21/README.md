# Урок 21. Автоматизація побудови моделі

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Автоматизувати погоджену побудову з кількома вхідними параметрами.

## Підготовка

Напрацювання уроків 17–20 і погоджені параметри побудови.

## Зміст

- постановка задачі автоматизації та визначення параметрів
- створення або адаптація скрипту для корисної повторюваної побудови
- перевірка геометрії, розмірів і стійкості роботи скрипту
- документування власних змін і використаної допомоги ШІ

## Практична робота № 9

- автоматизувати погоджену побудову з кількома вхідними параметрами
- перевірити результат на різних коректних значеннях
- самостійно перевірити кожну використану команду й отриману геометрію
- у звіті пояснити алгоритм, власні зміни та спосіб використання ШІ, якщо його застосовано

## Перевірка результату

В одному звіті Markdown або PDF покажіть два запуски та поясніть алгоритм, зміни й перевірку допомоги ШІ, якщо її використовували.
