# Урок 21. Штучний інтелект як помічник у моделюванні та програмуванні

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Скласти запит для пояснення фрагмента навчального скрипту.

## Підготовка

Короткий фрагмент коду без персональних даних і офіційна довідка CAD.

## Зміст

- формулювання запиту з контекстом, умовами й очікуваним результатом
- пояснення коду, пошук ідей та варіантів виправлення помилок
- можливі неточності, вигадані команди й упередження у відповідях ШІ
- захист персональних і конфіденційних даних, позначення використання ШІ

## Хід уроку та завдання

- скласти запит для пояснення фрагмента навчального скрипту
- порівняти відповідь ШІ з кодом і довідкою CAD-системи
- знайти твердження, які потребують додаткової перевірки

## Перевірка результату

Підтвердьте або спростуйте одне твердження ШІ за конкретним фрагментом коду чи довідки.
