# Урок 28. Підготовка моделі до друку. Слайсинг

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Підготувати навчальну модель до слайсингу.

## Підготовка

Готова модель і перевірений учителем профіль FDM-принтера та матеріалу.

## Зміст

- експорт моделі та призначення слайсера
- вибір профілю наявного FDM-принтера і матеріалу
- орієнтація моделі, висота шару, заповнення й підтримки
- попередній перегляд шарів та оцінка тривалості друку

## Хід уроку та завдання

- підготувати навчальну модель до слайсингу
- обрати налаштування за перевіреним профілем обладнання
- переглянути шари та пояснити вибір орієнтації
- підготувати файл для визначеного принтера після перевірки сумісності

## Перевірка результату

Порівняйте дві орієнтації за підтримками, часом і виглядом перших шарів.
