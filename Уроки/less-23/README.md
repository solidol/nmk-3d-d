# Урок 23. Проєктування коробки з кришкою

**Формат** — каркас уроку на одну академічну годину.

## Очікуваний результат

Створити ескізи корпусу та кришки.

## Підготовка

Погодьте призначення коробки, габарити та спосіб закривання.

## Зміст

- призначення коробки та спосіб закривання
- габарити корпусу й кришки
- товщина стінок та взаємне розташування деталей
- зазор з урахуванням навчального завдання й обладнання

## Хід уроку та завдання

- створити ескізи корпусу та кришки
- узгодити основні розміри, товщину стінок і зазор
- описати спосіб закривання коробки



[Завершальний етап роботи № 7](../less-24/README.md#практична-робота--7).

## Перевірка результату

Перевірте, чи обидва ескізи містять розміри, потрібні для побудови, і чи зазначено місце вимірювання зазору.
